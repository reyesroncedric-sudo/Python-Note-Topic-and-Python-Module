# Typing Speed Test Notes

This folder is organized to match the reference screenshot.

## Folder structure

- `01_time_module/`
  - `time_notes.md` — module explanation and connection to the original project
  - `time_examples.py` — three separate practical examples
- `02_random_module/`
  - `random_notes.md`
  - `random_examples.py`
- `03_string_module/`
  - `string_notes.md`
  - `string_examples.py`
- `04_typing_speed_test_project/`
  - `Typing_Speed_Test.py` — original project file
  - `project_overview.md` — summary of how the project works

## How to run the examples

You need Python 3. No external packages are required.

Open a terminal in the folder containing the module example file and run the relevant command, for example:

`python time_examples.py`

Other commands:
- `python random_examples.py`
- `python string_examples.py`

The time examples wait for keyboard input, so follow the prompts shown in the terminal.

To run the original project:

`python Typing_Speed_Test.py`

Run that command from inside `04_typing_speed_test_project`.

## Note
Each module's practical examples are in its own separate Python file, as requested. The notes explain where the same module is used in the original Typing Speed Test project.
